## Риски и открытые вопросы

| Риск | Что делаем |
|---|---|
| Нет официальных `train.json`/`sample_*` от организаторов | Сделали свой набор; запросить файлы у организаторов, прогонять `eval.py` на них |

| Район нельзя восстановить из строки | Заполнять по справочнику (за это отдельный балл на защите), не оставлять null там, где знаем ответ |
| Спорная трактовка `city` vs `living_area` для посёлков | Зафиксировать решение команды в README, показать жюри логику |
| Скорость на 1000 строк | Замер сделан (0.03 с); при росте справочника — проверить индексы SQLite |
| `street_type` не входит в метрику | Держим его заполненным из справочника: это «восстановление поля», смотрят на защите |
