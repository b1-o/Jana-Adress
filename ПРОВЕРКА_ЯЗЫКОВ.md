# Проверка языков и точности — копипаста

Всё работает офлайн, интернет не нужен. Команды для Arch Linux + fish.

---

## 1. Один раз: поставить зависимости

```fish
cd ~/Desktop/jana-final
python -m venv .venv
source .venv/bin/activate.fish
pip install -r requirements.txt
```

> `activate.fish` — именно так в fish. В bash было бы `source .venv/bin/activate`.

## 2. Главная команда — языки и точность

```fish
python scripts/lang_check.py
```

Что покажет:

| Группа | Сколько строк | Что проверяет |
|---|---|---|
| русский | 12 | обычный адрес, микрорайон, дробь `15/1`, область + город |
| казахский | 12 | `қаласы`, `даңғылы`, `көшесі`, `шағын ауданы`, `пәтер`, `кіреберіс`, `қабат`, `ауданы` |
| английский | 9 | `Almaty`, `Abay avenue`, `flat/apt/unit`, `district`, `floor` |
| смешанный | 5 | `город Алматы/Алматы қаласы`, `Абая 12 kv 5`, `Abay көшесі` |
| мусор | 11 | опечатки, слитное `Назарбаева8`, `66квартал 12дом 69квартира`, невидимые символы |
| другие языки | 7 | турецкий, немецкий, китайский, арабский, японский — **не поддерживаются**, проверяем что не упало |

## 3. Полезные варианты той же команды

```fish
python scripts/lang_check.py --verbose      # разбор каждой строки: все 14 полей
python scripts/lang_check.py --only kk      # только казахский
python scripts/lang_check.py --only en      # только английский
python scripts/lang_check.py --only dirty   # только «грязные» написания
python scripts/lang_check.py --json         # вывод в JSON, удобно для отчёта
```

`--verbose` печатает по каждой строке: область, город, район, жилмассив, улицу, дом,
квартиру, подъезд, этаж, уверенность — и знаком `✗` показывает, какое поле не совпало
с ожидаемым.

## 4. Свои примеры

Создать файл `data/lang_cases.json`:

```json
[
  {"group": "ru", "raw": "Алматы, улица Абая 12, кв 5",
   "city": "Алматы", "street_name": "Абая", "house": "12", "apartment": "5"},
  {"group": "kk", "raw": "Астана қ., Сарыарқа даңғылы 8",
   "city": "Астана", "street_name": "Сарыарқа", "house": "8"},
  {"group": "en", "raw": "Almaty, Abay avenue 12, flat 5",
   "city": "Алматы", "street_name": "Abay", "house": "12", "apartment": "5"}
]
```

`group` — один из `ru / kk / en / mix / dirty / other`.
Ожидаемые поля писать не обязательно: тогда строка попадёт только в статистику
«разобрано / уверенность».

## 6. Проверить то же через HTTP (как будет работать у жюри)

```fish

```


## 7. Какие языки система понимает — коротко

| Написание | Поддержка |
|---|---|
| Русский | ✅ полностью |
| Казахский, кириллица | ✅ полностью, включая `пәтер`, `кіреберіс`, `қабат`, `шағын ауданы` |
| Английский / латиница | ✅ через транслитерацию (`Almaty → алматы`, `Abay → абай`) |
| Смешанный, двуязычная склейка | ✅ |
| Турецкий, немецкий, узбекский латиницей | ⚠️ частично: город и дом находятся, служебные слова — нет |
| Китайский, арабский, японский, корейский | ❌ нет: вернётся `null` и `confidence ≈ 0`, пакет не падает |

Важно: неподдерживаемое письмо **не роняет** пакет. Запись проходит через
`_parse_one`, поэтому в ответе остаётся `raw_address` дословно и `confidence 0.0`.
